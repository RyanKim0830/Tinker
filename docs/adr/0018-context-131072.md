# ADR-0018: 사용자 실측에 따라 컨텍스트를 131072 로 설정한다

- **Status**: Accepted
- **Date**: 2026-10-05

## Context

[ADR-0002](0002-inference-server-llama-server.md) 는 컨텍스트를 `8192` 로 정했다. 사용자가 RTX 4050 Laptop 6GB 에서 Qwen3.6-35B-A3B Q4_K_M, `--cpu-moe`, KV q8_0 조건으로 메모리 사용량을 직접 측정했다 (2026-10-05).

| 컨텍스트 | 전용 GPU 메모리 | 공유 GPU 메모리 | 시스템 RAM | 사용자 판단 |
|---|---|---|---|---|
| 393216 | 5.7/6.0GB | 1.9GB | 31.2/31.6GB (99%) | VRAM 이 넘쳐 공유 메모리로 흘러감. 사용 불가 |
| 131072 | 3.8/6.0GB | 0.2GB | 17.2/31.6GB (54%) | 정상 |

## Decision

- ADR-0002 의 `-c 8192` 결정을 대체하여 Windows·WSL 스크립트 모두 **`-c 131072` (128K)** 를 쓴다. llama-server·포트·KV q8_0·reasoning 설정은 유지한다.
- 메모리 실측과 사용 가능 여부는 사용자의 관찰·판단으로 기록한다. 자동 메모리 판단이나 컨텍스트 한도 처리는 코드에 추가하지 않는다 ([ADR-0013](0013-no-judgment-in-code.md), [O-06](../open-items.md)).

## Considered Options

- 393216: 사용자 실측에서 공유 GPU 메모리와 RAM 사용량이 커 사용 불가로 판단했다.
- 8192 유지: 사용자 실측에서 131072 가 정상이며 더 긴 대화 컨텍스트를 확보할 수 있다.
- 자동 컨텍스트 조절·이력 삭제: 이번 범위에 포함하지 않는다.

## Consequences

- 이전보다 긴 컨텍스트를 제공한다. 한도 초과에 대한 앱의 처리는 여전히 없다.
- 두 값의 차이로 역산한 컨텍스트 토큰당 약 14KB 는 **KV 캐시 + 컨텍스트에 비례하는 버퍼를 포함한 추정치**다. 정확한 KV 캐시 토큰당 크기로 단정하지 않는다.
- 서버 로그의 KV 캐시 크기(MiB)는 아직 확인하지 않았다. WSL 실행에서도 같은 메모리 사용량인지 별도 확인하지 않았다.

## Revisit when

서버 로그의 KV 캐시·버퍼 크기를 확인하거나 모델·KV 양자화·하드웨어를 바꿀 때, 또는 실제 대화에서 컨텍스트 한도에 도달할 때.
