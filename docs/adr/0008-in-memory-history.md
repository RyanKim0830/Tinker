# ADR-0008: 대화 이력: 서버 메모리의 리스트 하나, session_id 없음

- **Status**: Accepted — 사용자 확정 (작업 지시서의 '확정된 결정')
- **Date**: 2026-10-03

## Context

사용자 1명, 첫 단계. 영속화(DB)는 이번 범위가 아니다.

## Decision

이력은 서버(`chat/service.py`)가 **인메모리 리스트 하나**로 보관한다. 서버 재시작하면 사라지는 것이 정상 동작이다. `session_id` 없음. CLI 는 이력을 들고 있지 않는다.

## Considered Options

- 클라이언트가 이력 전송: 서버가 단순해지나 요청이 커지고 CLI 가 상태를 가진다
- DB 영속화: 범위 밖(O-09)

## Consequences

- 서버를 재시작하면 대화가 초기화된다.
- 컨텍스트(8192) 한도 처리는 하지 않는다 → 대화가 길어지면 LLM 호출이 실패할 수 있다 (O-06).
- 동시 요청이 같은 이력을 건드린다 (O-07).

## Revisit when

대화를 재시작 뒤에도 이어가야 하거나, 클라이언트(앱/웹)가 늘어나 세션 구분이 필요할 때.
